# AI Bot — самонавчальний бот для Geometry Dash (мод для Geode)

Мод для **Geometry Dash 2.2081** + **Geode 5.11.1**. Бот сам пробує проходити рівні й вчиться на своїх смертях.

## Встановлення

1. Встанови [Geode](https://geode-sdk.org), якщо його ще немає.
2. Завантаж готовий файл мода (пряме посилання, завжди остання збірка):
   **https://github.com/And2010A/bottlebox/releases/download/gd-ai-bot-latest/and2010a.ai-bot.geode**
3. Поклади `and2010a.ai-bot.geode` у папку модів Geode:
   - **Windows:** `<папка гри>\geode\mods\` (папка гри — там, де `GeometryDash.exe`; у Steam: ПКМ по грі → Керувати → Переглянути локальні файли);
   - **Android:** через Geode Launcher → Settings → Open game folder → `geode/mods/`;
   - **macOS:** `~/Library/Application Support/GeometryDash/geode/mods/`.
4. Перезапусти гру. У списку модів Geode з'явиться **AI Bot**.

## Помилка «Точка входа ... __std_calloc_crt не найдена ... Geode.dll»

Це не помилка мода: на ПК застаріла бібліотека Microsoft Visual C++, потрібна Geode. Якщо оновити її не можна:
1. Завантаж **https://github.com/And2010A/bottlebox/releases/download/gd-ai-bot-latest/vc-runtime-x64.zip** — це офіційні DLL від Microsoft з Visual Studio.
2. Розпакуй **усі** файли з архіву в папку гри, поруч із `GeometryDash.exe`. Якщо Windows спитає про заміну файлів — погоджуйся.
3. Запусти гру знову.

## Як користуватися

1. Зайди в будь-який рівень і натисни **паузу**.
2. У лівому верхньому куті — кругла кнопка **AI**.
3. У вікні:
   - **Enabled** — увімкнути бота;
   - **Learning** — вчитися (якщо вимкнути, бот лише показує вже вивчене);
   - **Memory / Human** — режим навчання;
   - **Speed** — прискорення гри для швидшого тренування (x0.25…x8);
   - **Reset level** — стерти пам'ять бота на цьому рівні;
   - **Reset brain** — стерти нейромережу режиму Human;
   - **Settings** — додаткові налаштування (затримка реакції, неточність, шанс промаху, розмір популяції тощо).
4. Натисни **рестарт** — бот почне з наступної спроби.

У куті екрана видно, що робить бот: номер спроби, рекорд, покоління.

## Режими навчання

### Memory (Засвоєння)
Фізика GD детермінована: ті самі натискання в ті самі тіки (240 на секунду) дають той самий результат. Бот:
- запам'ятовує натискання найдальшої спроби;
- повторює їх до місця трохи раніше за смерть і звідти пробує нові варіанти;
- запам'ятовує **кожну** послідовність, що закінчилась смертю, і ніколи не грає її знову;
- якщо довго не виходить, починає змінювати рухи ще раніше.

Результат: пройдене місце він більше не провалює, і рівень рано чи пізно буде пройдено. Після цього бот проходить його щоразу. Пам'ять зберігається окремо для кожного рівня (і для кожної start pos).

### Human (Як людина)
- Бот «бачить» сітку 8×7 клітинок навколо себе: блоки, шипи, сфери/пади, а ще свою швидкість, чи стоїть на землі, чи це міні-режим.
- Для кожного режиму (куб, корабель, кулька, НЛО, хвиля, робот, павук, свінг) — **окрема маленька нейромережа**. На старті в неї вже закладено «інстинкт», наприклад «шип попереду → стрибай».
- Натискання відбувається із **затримкою реакції**, **випадковою неточністю** і з невеликим **шансом проґавити клік**. Тому бот може померти на тому самому місці, як людина.
- Навчання — еволюція: кожна спроба грає один варіант «мозку», найкращі варіанти схрещуються й мутують. Мозок один на всі рівні, тож досвід переноситься.

## Важливо
- Поки бот грає, твої кліки ігноруються.
- Щойно бот був увімкнений у рівні, **прогрес не зберігається** до виходу з рівня, як при грі зі start pos. Це захист від випадкових «нечесних» рекордів.
- Режим практики й платформер-рівні не підтримуються.
- Детермінізм GD не ідеальний: інколи повтор може «розсинхронізуватись», і бот помре там, де раніше проходив. Він просто продовжить навчання з цього місця.
- Файли пам'яті лежать у `geode/save/and2010a.ai-bot/` (`memory/*.bin` — для режиму Memory, `brain.bin` — для режиму Human).

## Збірка з коду

Потрібні [Geode SDK і CLI](https://docs.geode-sdk.org/getting-started/geode-cli):

```sh
cd gd-ai-bot
geode build
```

Або просто запуш зміни — GitHub Actions збере `.geode` для Windows, macOS і Android.
