# AI Bot — самонавчальний бот для Geometry Dash (мод для Geode)

Мод для **Geometry Dash 2.2081** + **Geode 5.11.1**. Бот сам пробує проходити рівні й вчиться на своїх смертях.

## Встановлення

1. Встанови [Geode](https://geode-sdk.org), якщо його ще немає.
2. Завантаж готовий файл мода (пряме посилання, завжди остання збірка):
   **https://github.com/And2010A/bottlebox/releases/download/gd-ai-bot-latest/and2010a.ai-bot.geode**
3. Поклади `and2010a.ai-bot.geode` у папку модів Geode:
   - **Windows:** `<папка гри>\geode\mods\` (папка гри — там, де `GeometryDash.exe`; у Steam: ПКМ по грі → Керувати → Переглянути локальні файли);
   - **Android:** через Geode Launcher → Settings → Open game folder → `geode/mods/`;
   - **macOS:** `~/Library/Application Support/GeometryDash/geode/mods/`.
4. Перезапусти гру. У списку модів Geode з'явиться **AI Bot**.

## Помилка «Точка входа ... __std_calloc_crt не найдена ... Geode.dll»

Це не помилка мода: на ПК застаріла бібліотека Microsoft Visual C++, потрібна Geode. Якщо оновити її не можна:
1. Завантаж **https://github.com/And2010A/bottlebox/releases/download/gd-ai-bot-latest/vc-runtime-x64.zip** — це офіційні DLL від Microsoft з Visual Studio.
2. Розпакуй **усі** файли з архіву в папку гри, поруч із `GeometryDash.exe`. Якщо Windows спитає про заміну файлів — погоджуйся.
3. Запусти гру знову.

## Як користуватися

1. Зайди в будь-який рівень і натисни **паузу**.
2. У лівому верхньому куті — кругла кнопка **AI**.
3. У вікні:
   - **Enabled** — увімкнути бота;
   - **Learning** — вчитися (якщо вимкнути, бот лише показує вже вивчене);
   - **Memory / Human / Macro** — режим (див. нижче);
   - **Speed** — прискорення гри для тренування: x0.25 … x20;
   - **Reset level** — стерти пам'ять бота на цьому рівні;
   - **Reset brain** — стерти весь досвід бота (з усіх рівнів);
   - **Macros** — відкрити папку з макросами, логом прогресу й пам'яттю бота;
   - **Settings** — додаткові налаштування (затримка реакції, неточність, шанс промаху).
4. Натисни **рестарт** — бот почне з наступної спроби.

У куті екрана видно, що робить бот: рівень «мозку», скільки рівнів пройдено, номер спроби, рекорд.

## «Мозок» — бот справді розвивається

У бота є один спільний **мозок** на всі рівні: маленькі нейромережі (окремі для куба, корабля, кульки, НЛО, хвилі, робота, павука, свінгу). Він «бачить» сітку 8×7 клітинок навколо себе: блоки, шипи, сфери/пади, а ще свою швидкість, чи стоїть на землі, гравітацію, міні-режим.

- Щоразу, коли бот проходить далі, ніж раніше, він **запам'ятовує, що робив** у пройденій частині. Те, що було за пів секунди до смерті, не запам'ятовує: це, мабуть, і була помилка.
- Мозок **тренується на цьому досвіді у фоні**, тому гра не зависає. У HUD у цей час написано «thinking...».
- Досвід переноситься: пройшов **Stereo Madness** — на **Back on Track** він уже вміє базові стрибки й не починає з нуля.
- Видно, як він росте: **Brain lv** (рівень мозку), кількість пройдених рівнів, вивчених рухів і точність. На кожному новому рівні бот показує «First try: …%» — скільки він проходить з першої спроби. Що більше досвіду, то більше цей відсоток.
- Усе записується в **`progress.csv`** (відкривається в Excel чи Google Таблицях): час, рівень, перша спроба, рекорди, проходження.

У тестах на спрощеній моделі гри бот після першого пройденого рівня проходив нові рівні з першої спроби. Справжні рівні GD складніші, тож там прогрес буде повільнішим, але принцип той самий.

## Режими

### Memory (Засвоєння) — вчиться на помилках
Фізика GD детермінована: ті самі натискання в ті самі тіки (240 на секунду) дають той самий результат. Тому бот:
- запам'ятовує натискання найдальшої спроби і пройдене місце більше ніколи не провалює;
- коли помирає, **розбирає свою помилку**: дивиться на останні натискання перед смертю і перевіряє конкретні гіпотези — «стрибнути раніше», «стрибнути пізніше», «тут потрібен ще один стрибок», «цей стрибок був зайвий», «тримати довше / коротше», «на мить відпустити»;
- кожну гіпотезу перевіряє **одною спробою** і ніколи не повторює ту, що вже не спрацювала;
- якщо виправлення допомогло лише трохи (бот помер на тій самій перешкоді, але трохи далі), він робить те саме сміливіше (×2, ×1,5, ×3), а не пробує навмання;
- **запам'ятовує, які виправлення спрацьовують**, окремо для кожного режиму й ситуації, і наступного разу пробує їх першими. Тобто вчиться не лише рівню, а й тому, як виправляти помилки;
- у польоті куба, кульки чи павука (без сфер поруч) не натискає зовсім: там натискання нічого не змінює, тож кожне натискання в пам'яті — справжній стрибок.

У куті екрана видно: «Deaths at this spot: 2 | fixing the mistake: jump earlier» — скільки разів помер на цьому місці і яку гіпотезу зараз перевіряє.

На тестовій моделі гри: на найпершій перешкоді «порожній» бот помирає до 6–8 разів. Далі зазвичай **1–2 смерті на місце**, а наступні рівні проходить з першої спроби. Справжні рівні GD складніші, тож на важких місцях (вузька хвиля, складні таймінги) смертей може бути більше. Але бот ніколи не повторює ту саму помилку двічі.

### Human (Як людина)
Грає тим самим мозком, але як людина: з **затримкою реакції** (дивиться трохи вперед, як людина, що реагує заздалегідь), **неточністю** і **шансом проґавити клік**. Тому може померти там, де вже пролітав. Вчиться на своїх рекордах і хороших спробах, а якщо довго застряг — починає експериментувати.

### Macro
Коли бот проходить рівень (у режимі Memory або Human), **проходження автоматично зберігається як макрос** у файл на твоєму ПК. У режимі **Macro** бот просто відтворює цей макрос.

## Де лежать файли

Кнопка **Macros** у вікні бота відкриває цю папку:
`C:\Users\<твоє ім'я>\AppData\Local\GeometryDash\geode\mods\and2010a.ai-bot\`

- `macros\<назва рівня> [<ID>].json` — макроси (один на рівень). Формат: `inputs` — список `[тік, гравець (1/2), натиснуто (1/0)]`, 240 тіків на секунду;
- `progress.csv` — журнал розвитку бота;
- `skill.bin`, `experience.bin` — мозок і досвід;
- `fixes.bin` — які виправлення помилок спрацьовують;
- `memory\*.bin` — пам'ять режиму Memory для кожного рівня.

Макрос можна скопіювати в ту саму папку на іншому ПК — бот його підхопить.

## Важливо
- Поки бот грає, твої кліки ігноруються.
- Щойно бот був увімкнений у рівні, **прогрес не зберігається** до виходу з рівня, як при грі зі start pos. Це захист від випадкових «нечесних» рекордів.
- Режим практики й платформер-рівні не підтримуються.
- Фізика GD повторюється не ідеально (особливо на великій швидкості): той самий набір натискань може дати трохи інший політ. Тому бот запам'ятовує точну позицію гравця на кожному тіку рекорду (і макросу) і під час повтору підправляє дрібні відхилення — у HUD це «sync fixes».

## Збірка з коду

Потрібні [Geode SDK і CLI](https://docs.geode-sdk.org/getting-started/geode-cli):

```sh
cd gd-ai-bot
geode build
```

Або просто запуш зміни — GitHub Actions збере `.geode` для Windows, macOS і Android.
