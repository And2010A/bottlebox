# v0.3.0
- Режим Memory вчиться на помилках: після смерті перевіряє конкретні гіпотези («стрибнути раніше/пізніше», «додати/прибрати стрибок», «тримати довше/коротше»), по одній на спробу, без повторів.
- Якщо виправлення допомогло лише трохи, бот посилює його (×2, ×1,5, ×3).
- Бот запам'ятовує, які виправлення працюють у кожному режимі й ситуації, і пробує їх першими (`fixes.bin`).
- Куб, кулька й павук не натискають у польоті без сфер — кожне натискання в пам'яті справжнє.
- HUD показує, скільки разів бот помер на поточному місці і яку гіпотезу перевіряє.

# v0.2.0
- Спільний «мозок», що вчиться на кожному успіху та переносить досвід між рівнями (тренується у фоні).
- Режим Memory пробує нові рухи за підказкою мозку.
- Автозбереження макросу після проходження й новий режим Macro для відтворення.
- Журнал розвитку `progress.csv`, рівень мозку в HUD, сповіщення про пройдений рівень.
- Кнопка «Macros» відкриває папку з файлами бота.
- Швидкість до x20.
