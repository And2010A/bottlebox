# Інструкція для Word 2010 (російський інтерфейс)

Як працювати з цією інструкцією:

1. Зробіть налаштування з розділу **«0. Спочатку»** (поля, шрифт за замовчуванням).
2. Скопіюйте **весь текст варіанта** (сірий блок на початку варіанта) і вставте в Word **тільки текстом** (див. нижче).
3. Ідіть по пунктах 1.1, 1.2, … — у кожному пункті показано, **який шматок тексту** оформлюємо, і **що саме натиснути**.

Назви кнопок написані **точно так, як у вашому Word** («Главная», «Вставка», «Разметка страницы»…).

---

## 0. Спочатку

### Як вставити текст без оформлення
Скопіювати блок (виділити → Ctrl+C) → у Word: вкладка **«Главная»** → під кнопкою **«Вставить»** натиснути
**стрілочку** → у «Параметры вставки» значок **«A»** (**«Сохранить только текст»**).
Або: правою кнопкою миші → у «Параметры вставки:» значок **«A»**.
Кожен рядок блоку стане окремим абзацом, порожній рядок — порожнім абзацом (вони потрібні, не видаляйте).

### Налаштування документа
1. **«Разметка страницы» → «Поля» → «Настраиваемые поля…»**: верхнее **1,5**, нижнее **1,5**, левое **2,5**,
   правое **2 см**; вкладка **«Размер бумаги»** → **A4** → OK.
2. **Ctrl+D** → шрифт **Times New Roman**, размер **13** → кнопка **«По умолчанию…»** → **«всех документов…»** → OK.
3. Вікно **«Абзац»**: Интервал перед **0**, после **0**, междустрочный **Одинарный** → **«По умолчанию…»** → OK.

### Де що знаходиться

| Що потрібно | Куди натискати |
|---|---|
| **Вікно «Шрифт»** | **«Главная»** → група **«Шрифт»** → маленька стрілочка ↘ у правому нижньому куті (або **Ctrl+D**) |
| **Вікно «Абзац»** | **«Главная»** → група **«Абзац»** → стрілочка ↘ у правому нижньому куті |
| **Вікно «Границы и заливка»** | **«Главная»** → група **«Абзац»** → кнопка **«Граница»** (квадратик з лініями, в нижньому ряду) → стрілка біля неї → в самому низу **«Границы и заливка…»** |
| **Рамка сторінки** | **«Разметка страницы»** → **«Границы страниц»** |
| **Значок** | **«Вставка»** → **«Символ»** → **«Другие символы…»** |
| **Буквиця** | **«Вставка»** → **«Буквица»** → **«Параметры буквицы…»** |
| **Таблиця** | **«Вставка»** → **«Таблица»** |
| **Межі таблиці** | клацнути в таблицю → зверху **«Работа с таблицами»** → вкладки **«Конструктор»** і **«Макет»** |

### Прийоми, які повторюються
**А. Рамка з тінню + заливка абзацу.** Курсор у потрібний рядок → **«Границы и заливка…»** → вкладка
**«Граница»**: ліворуч **«тень»**, посередині суцільна лінія, **«Цвет:»**, **«Ширина:»**, внизу праворуч
**«Применить к:» абзацу** → вкладка **«Заливка»** → колір, **«Применить к:» абзацу** → OK.

**Б. Лінія тільки з одного боку.** **«Границы и заливка…»** → **«Граница»** → ліворуч **«другая»** → лінія,
**«Цвет:»**, **«Ширина:»** → у полі **«Образец»** клацнути по потрібній стороні → **«Применить к:» абзацу**.
Відстань лінії від тексту — кнопка **«Параметры…»** (поля в пунктах).

**В. Вікно «Шрифт» (Ctrl+D).** Вкладка **«Шрифт»**: «Подчеркивание:», галочки «зачеркнутый», «малые прописные».
Вкладка **«Дополнительно»**: **«Масштаб:»**, **«Интервал:» Разреженный / Уплотненный «на:»**, **«Смещение:» Вниз «на:»**.

**Г. Значок.** Поставити курсор у потрібне місце → **«Вставка» → «Символ» → «Другие символы…»** →
**«Шрифт:»** Wingdings або Symbol → внизу **«из:» символ (дес.)** → **«Код знака:»** число → **«Вставить»** → «Закрыть».

**Д. Рамка або фон навколо одного слова.** Виділити слово → **«Границы и заливка…»** → **«Применить к:» тексту**.

**Колір RGB.** У списку кольорів → **«Другие цвета…»** → вкладка **«Спектр»** → модель **RGB** →
**«Красный» / «Зеленый» / «Синий»**:

| Назва | RGB | Назва | RGB |
|---|---|---|---|
| темно-червоний | 192, 0, 0 | світло-жовтий | 255, 242, 204 |
| темно-помаранчевий | 197, 90, 17 | світло-зелений | 226, 239, 218 |
| фіолетовий | 112, 48, 160 | світло-блакитний | 222, 235, 247 |
| синій | 0, 112, 192 | світло-персиковий | 251, 229, 214 |
| темно-зелений | 84, 130, 53 | персиковий | 248, 203, 173 |
| | | жовтий | 255, 230, 153 |

```text
Для створення Web-сторінок використовуються спеціальні мови розмітки, що дозволяють керувати форматуванням, розташуванням і функціональністю елементів, які містяться на сторінках. Найбільш поширеною у Web є мова  (HYPER TEXT Markup Language-мова гіпертекстової розмітки).
Документи HTML являють собою текст, у якому містяться спеціальні команди (або ТЕГИ), що визначають форматування сторінок і дозволяють розташовувати на ній гіперпосилання, зображення, спеціальні елементи форматування і певну службову інформацію.
Тег завжди міститься між дужками < > і має такий вигляд:
<ТЕГ атрибуті = ЗНАЧЕННЯ ... атрибут N = ЗНАЧЕННЯ >
Теги бувають поодинокими і контейнерними. Контейнером називається пара відкриваючий <Тег> і закриваючий </ТЕГ>.

Структура простого HTML-документа

<HTML> - Початок документа
<HEAD>
ЗАГОЛОВОК ДОКУМЕНТА
</HEAD>
<BODY>
ТІЛО ДОКУМЕНТА
</BODY>
</HTML>

Теги стилістичного виділення тексту

<STRIKE>...</STRIKE> - Виділення перекреслюванням (Помилка)
<B>...</B> Виділення напівжирним шрифтом (Інформатика)
<I>...</I> Виділення курсивом (Програмування)
<U>...</U> Виділення підкреслюванням (Бази даних)
<SUP>...</SUP> Шрифт у верхньому індексі (xy)
<SUB>...</SUB> Шрифту нижньому індексі (Температурасічнева)
НУМЕРОВАНИЙ список починається з тега <OL> і закривається тегом </OL>.
Тег <OL> може мати такі параметри:
TYPE - вид лічильника:
A - великі латинські літери
a - маленькі латинські літери
I - великі римські літери
i - маленькі римські літери
1 - звичайні цифри
START - встановлює число,  яким буде починатися список.
Хмельницький політехнічний коледж. Навчальна дисципліна "Інформатика"
```

### 2.1 Рамка сторінки зі знаків радіації
Нічого виділяти не треба. **«Разметка страницы» → «Границы страниц»** → **«Страница»** → **«Рисунок:»** →
**кружечки-знаки радіації** (у каталозі `Ramky_vybir.docx` це сторінка **№ 9**) → **«Цвет:»** темно-червоний →
**«Ширина:» 16 пт** → **«Применить к:» всему документу** → **«Параметры…»** → **края страницы**, усі поля **20 пт** → OK → OK.

### 2.3 Три заголовки з точковою рамкою і товстою тінню
Так оформлюються три рядки:
```text
Основні теги мови HTML для створення гіпертекстового документа
Структура простого HTML-документа
Теги стилістичного виділення тексту
```
Для **кожного** з них (над і під кожним уже є порожній рядок):
1. Курсор на початок заголовка → прийом **Г**: шрифт **Symbol**, код **167** (♣) для 1-го, **169** (♥) для 2-го,
   **168** (♦) для 3-го → натиснути пробіл. Так само поставити значок і в кінці рядка (пробіл перед значком).
2. Виділити весь рядок заголовка → **«Вставка» → «Таблица» → «Преобразовать в таблицу…»** →
   **«Число столбцов:» 1** → OK. Рядок опиниться в таблиці з однієї клітинки.
3. Клацнути в таблицю → **«Работа с таблицами» → «Макет» → «Свойства»** → вкладка **«Таблица»**:
   **«Ширина:» 16,5 см**, выравнивание **по центру** → кнопка **«Параметры…»** → поля ячеек:
   верхнее **0,07**, нижнее **0,1**, левое **0,07**, правое **0,1 см** → OK → OK.
4. **«Конструктор» → «Границы»** (стрілка) → **«Нет границы»**.
   Потім у групі «Нарисовать границы»: **«Стиль пера»** суцільна лінія, **«Толщина пера» 3 пт**,
   **«Цвет пера»** чорний → **«Границы» → «Правая граница»**, ще раз **«Границы» → «Нижняя граница»** (це тінь).
5. Курсор у текст заголовка → **«Границы и заливка…»** → **«Граница»** → тип **«рамка»** → лінія **з крапок** →
   **«Ширина:» 1,5 пт** → колір (таблиця нижче) → **«Параметры…»** → усі поля **2 пт** → вкладка **«Заливка»** →
   колір → **«Применить к:» абзацу** → OK. Текст — **по центру**.
6. Порожній рядок **над** таблицею → «Абзац»: междустрочный **Точно**, **5 пт** (для першого заголовка — **4 пт**);
   порожній рядок **під** таблицею → **Точно 3 пт** (для першого — **4 пт**).

| Заголовок | Шрифт тексту | Колір крапкової рамки | Заливка |
|---|---|---|---|
| Основні теги… | **Arial 13 Ж**, Разреженный **2 пт** | темно-помаранчевий | світло-жовта |
| Структура… | **Arial 13 Ж**, Разреженный **3 пт** | синій | світло-блакитна |
| Теги стилістичного… | **Times New Roman 13 Ж + К**, Разреженный **3 пт** | темно-червоний | світло-персикова |

### 2.10 Шість рядків з тегами
```text
<STRIKE>...</STRIKE> - Виділення перекреслюванням (Помилка)
<B>...</B> Виділення напівжирним шрифтом (Інформатика)
<I>...</I> Виділення курсивом (Програмування)
<U>...</U> Виділення підкреслюванням (Бази даних)
<SUP>...</SUP> Шрифт у верхньому індексі (xy)
<SUB>...</SUB> Шрифту нижньому індексі (Температурасічнева)
```
1. Усі шість рядків → розмір **12**.
2. **«Помилка»** → **Ctrl+D** → галочка **«зачеркнутый»**.
3. **«Інформатика»** → Ж. **«Програмування»** → К. **«Бази даних»** → Ч.
4. У «(xy)» виділити тільки **«y»** → кнопка **x²** на «Главной» (верхній індекс).
5. У «(Температурасічнева)» виділити **«січнева»** → кнопка **x₂** (нижній індекс).

### Якщо щось «прилипло»
Word переносить рамку/заливку на сусідні рядки, якщо вони були оформлені однаково. Якщо рамка або заливка
з'явилась там, де її не має бути: курсор у цей рядок → **«Границы и заливка…»** → вкладка «Граница» тип **«нет»**,
вкладка «Заливка» **«Нет цвета»** → **«Применить к:» абзацу**.
