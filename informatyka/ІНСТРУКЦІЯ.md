## 0. Спільне для обох документів (робиться першим)

1. **Розмір і поля.** *Макет → Поля → Настроювані поля…*
   Верхнє **1,5 см**, нижнє **1,5 см**, ліве **2,5 см**, праве **2 см**.
   На вкладці *Розмір паперу* — **A4**. На вкладці *Джерело паперу* → *Від краю до колонтитула: нижнього* **0,7 см**.
2. **Шрифт за замовчуванням.** *Головна →* стрілочка в куті групи *Шрифт* (або **Ctrl+D**):
   **Times New Roman, 13** → кнопка *За замовчуванням…* → *Усі документи*.
3. **Абзац за замовчуванням.** *Головна →* стрілочка в куті групи *Абзац*:
   *Інтервал перед* **0**, *після* **0**, *міжрядковий* **одинарний** → *За замовчуванням…*.
4. **Нижній колонтитул** («ХПК НУ «ЛП»» і номер сторінки):
   *Вставлення → Нижній колонтитул → Пустий*. У колонтитулі: *Головна → Абзац → Табуляція…*
   додати позицію **8,25 см — по центру**, потім **16,5 см — по правому краю**.
   Набрати: **Tab** `ХПК НУ «ЛП»` **Tab** `- 13 -` (у Варіанті 2 — `- 14 -`).
   Шрифт Times New Roman **12**, «ХПК НУ «ЛП»» — **жирний** (Ctrl+B).
   Лапки «» — *Вставлення → Символ → Інші символи* (або Alt+0171 / Alt+0187).

### Як робиться «рамка з тінню» (заголовки в сірих/кольорових прямокутниках)

Цей прийом використовується багато разів, тому описую один раз:

1. Поставити курсор в абзац заголовка (виділяти не обов'язково — рамка ставиться на весь абзац).
2. *Головна → група Абзац →* стрілка біля кнопки **Межі** → **Межі та заливка…** (в самому низу списку).
3. Вкладка **Межа**: ліворуч *Тип* → **Тінь**; *Тип лінії* — суцільна; *Колір* — потрібний колір;
   *Ширина* — **1 пт** (якщо не сказано інше); *Застосувати до:* **абзацу**.
4. Вкладка **Заливка**: *Заливка* → *Інші кольори* → RGB потрібного кольору; *Застосувати до:* **абзацу** → **OK**.

### Як робиться «розріджений» шрифт (літери з великими проміжками)

Виділити текст → **Ctrl+D** → вкладка **Додатково** → *Інтервал:* **Розріджений**, *на:* N пт.
(Від'ємне значення = *Ущільнений*.) Там же — *Зміщення: Униз / Угору* на N пт.

### Як вставити значок (мишка, дискета, ♣, ⇒ тощо)

*Вставлення → Символ → Інші символи…* → вкладка *Символи* → *Шрифт:* **Wingdings** або **Symbol** →
внизу в полі *Код знака* ввести десяткове число (*з: символ (десяткове)*) → **Вставити**.

*Межі та заливка*: *Заливка* **E2EFDA**; *Межа → Інший* → суцільна **2¼ пт** 385723, клацнути **лише нижню** межу.

---

### Примітки
- Якщо на комп'ютері немає шрифтів **Bookman Old Style** або **Monotype Corsiva**, Word підставить інші —
  вони входять до пакета Microsoft Office і звичайно вже встановлені.
- Межі сторінки-малюнки (ноти, кружечки) видно тільки у Word; у LibreOffice/Google Docs їх не буде.
- Рукописні дужки та позначки на полях аркуша — це нотатки викладача про шрифти, у документ їх не переносимо.
