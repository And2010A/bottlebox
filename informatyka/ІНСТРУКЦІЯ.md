# Як відтворити аркуші 1:1 у Microsoft Word

Файли: `Variant_1.docx` (Варіант 1) і `Variant_2.docx` (Варіант 2).
Шрифти взято з аркуша та з рукописних позначок на ньому: **Ar** = Arial, **Times** = Times New Roman,
**CN** = Courier New, **Bookman Old Style**, **Monotype Corsiva**.
Кольори навмисно **мішані** (кожен блок свого кольору), щоб було видно, що документ оформлював студент.
Колонтитула «ХПК НУ «ЛП»» і номера сторінки **немає**.

## 0. Спільне для обох документів (робиться першим)

1. **Розмір і поля.** *Макет → Поля → Настроювані поля…*
   Верхнє **1,5 см**, нижнє **1,5 см**, ліве **2,5 см**, праве **2 см**. *Розмір паперу* — **A4**.
2. **Шрифт за замовчуванням.** **Ctrl+D** → **Times New Roman, 13** → *За замовчуванням…* → *Усі документи*.
3. **Абзац за замовчуванням.** *Головна →* стрілочка в куті групи *Абзац*:
   *перед* **0**, *після* **0**, *міжрядковий* **одинарний** → *За замовчуванням…*.

### Прийоми, які повторюються

**А. Рамка з тінню + заливка абзацу** (заголовки Варіанта 1):
курсор в абзац → *Головна → Абзац →* стрілка біля кнопки **Межі** → **Межі та заливка…** →
вкладка **Межа**: *Тип* **Тінь**, лінія суцільна, *Колір*, *Ширина* **1½ пт**, *Застосувати до:* **абзацу** →
вкладка **Заливка**: колір, *до абзацу* → OK.

**Б. Межа лише з одного боку:** там само *Тип* **Інший** → обрати лінію/колір/ширину →
у *Зразку* праворуч **клацнути по потрібній стороні** (ліва / права / нижня) → *до абзацу*.

**В. Розріджений шрифт:** виділити → **Ctrl+D** → вкладка **Додатково** → *Інтервал:* **Розріджений на N пт**
(для *Ущільнений* — так само). Там же *Зміщення: Униз на N пт*.

**Г. Значок:** *Вставлення → Символ → Інші символи…* → *Шрифт:* **Wingdings** або **Symbol** →
поле *Код знака* (з: *символ (десяткове)*) → **Вставити**. Колір значка — як звичайного тексту.

**Д. Рамка/фон навколо одного слова:** виділити слово → *Межі та заливка* → *Застосувати до:* **тексту**.

## ВАРІАНТ 2 — `Variant_2.docx`

### 2.1 Рамка сторінки зі знаків радіації ☢
У Word серед готових «Малюнків» меж сторінки знака радіації немає, тому рамка складається
з **чотирьох написів (текстових полів)** у колонтитулі — так вона сама повторюється на кожній сторінці
і не заважає набирати текст.

1. Двічі клацнути у верхньому полі сторінки → відкриється **Верхній колонтитул**.
2. *Вставлення → Текстове поле → Простий напис*. Видалити текст-підказку.
3. Вставити знак ☢: *Вставлення → Символ → Інші символи* → *Шрифт:* **Segoe UI Symbol** →
   *Код знака* **2622**, *з:* **Юнікод (шістн.)** → *Вставити*.
   (Або набрати `2622` і одразу натиснути **Alt+X**.) Розмір **14**, колір **темно-червоний**.
4. **Верхній напис:** скопіювати ☢ і вставити, щоб у рядку було **33** знаки.
   Абзац → *Вирівнювання* **Розподілений** (Ctrl+Shift+J) — знаки рівномірно розійдуться на всю ширину.
5. Формат напису (*Формат фігури*):
   - *Контур фігури* → **Без контуру**; *Заливка фігури* → **Без заливки**;
   - *Розмір*: висота **0,67 см**, ширина **19,8 см**;
   - *Положення → Додаткові параметри розмітки*: *По горизонталі* — **абсолютне 0,6 см праворуч від сторінки**,
     *По вертикалі* — **абсолютне 0,6 см нижче сторінки**; *Обтікання текстом* — **За текстом**;
   - *Формат фігури → Параметри тексту → Напис*: усі поля (ліве, праве, верхнє, нижнє) **0 см**.
6. **Нижній напис:** скопіювати верхній (Ctrl+C, Ctrl+V) і поставити *по вертикалі* **28,43 см нижче сторінки**.
7. **Лівий напис:** новий напис шириною **0,67 см** і висотою **27,16 см**; усередині **45** знаків ☢,
   **кожен в окремому абзаці** (☢, Enter, ☢, Enter…), вирівнювання **по центру**,
   *міжрядковий інтервал* **Точно 21 пт**, *перед/після* **0**. Положення: **0,6 см** від лівого краю сторінки,
   **1,27 см** нижче верхнього краю сторінки. Без контуру й заливки, поля напису **0**.
8. **Правий напис:** копія лівого, *по горизонталі* **19,73 см** праворуч від сторінки.
9. Закрити колонтитул (*Закрити вікно колонтитулів*). У колонтитулі більше нічого не писати.
