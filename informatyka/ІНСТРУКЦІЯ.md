# Як відтворити аркуші 1:1 у Microsoft Word

Файли: `Variant_1.docx` (Варіант 1) і `Variant_2.docx` (Варіант 2). Усе зроблено **лише засобами Word**.
Шрифти — з аркуша та з позначок на полях: **Ar** = Arial, **Times** = Times New Roman, **CN** = Courier New,
**Bookman Old Style**, **Monotype Corsiva**.
**Текст скрізь чорний, як на аркуші.** Кольоровими (мішаними) зроблено тільки те, що на аркуші сіре або є лінією:
заливки, рамки, смуги, лінії. Колонтитула «ХПК НУ «ЛП»» і номера сторінки немає.

## Палітра

*Заливка / Колір лінії → Інші кольори → вкладка «Спектр»* → ввести RGB.

| Назва | RGB | Назва | RGB |
|---|---|---|---|
| темно-червоний | 192, 0, 0 | світло-жовтий | 255, 242, 204 |
| темно-помаранчевий | 197, 90, 17 | світло-зелений | 226, 239, 218 |
| фіолетовий | 112, 48, 160 | світло-блакитний | 222, 235, 247 |
| синій | 0, 112, 192 | світло-персиковий | 251, 229, 214 |
| темно-зелений | 84, 130, 53 | персиковий | 248, 203, 173 |
| | | жовтий | 255, 230, 153 |

## 0. Спільне для обох документів

1. *Макет → Поля → Настроювані поля*: верхнє **1,5**, нижнє **1,5**, ліве **2,5**, праве **2 см**; папір **A4**.
2. **Ctrl+D** → **Times New Roman 13** → *За замовчуванням* → *Усі документи*.
3. *Абзац*: *перед* **0**, *після* **0**, **одинарний** → *За замовчуванням*.

### Прийоми, які повторюються

**А. Рамка з тінню + заливка абзацу:** курсор в абзац → *Головна → Абзац →* стрілка біля кнопки **Межі** →
**Межі та заливка…** → *Межа*: *Тип* **Тінь**, суцільна, колір, **1½ пт**, *до абзацу* → *Заливка*: колір, *до абзацу*.

**Б. Лінія лише з одного боку:** *Межі та заливка → Межа* → *Тип* **Інший** → лінія, колір, ширина →
у *Зразку* клацнути по потрібній стороні → *до абзацу*.

**В. Ctrl+D → вкладка «Додатково»:** *Інтервал* **Розріджений / Ущільнений на N пт**;
**Масштаб N %** (розтягнути літери в ширину); *Зміщення* **Униз на N пт**.

**Г. Значок:** *Вставлення → Символ → Інші символи* → *Шрифт* **Wingdings** або **Symbol** →
поле *Код знака* (з: *символ (десяткове)*) → *Вставити*.

**Д. Рамка/фон навколо одного слова:** виділити слово → *Межі та заливка* → *Застосувати до:* **тексту**.

## ВАРІАНТ 1

### 1.1 Рамка сторінки з нот
*Конструктор → Межі сторінок* → вкладка **Сторінка** → поле **Малюнок** → **музичні ноти ♫** →
*Колір* **фіолетовий**, *Ширина* **18 пт** → *Застосувати до:* всього документа →
*Параметри* → *Відносно:* **краю сторінки**, усі поля **20 пт**.

### 1.2 «Варіант 1» у смузі і «Білет № 14»
- `Варіант 1` — Arial **16, жирний**, по центру. Прийом **А** без рамки: тільки *Заливка* **персиковий** (до абзацу).
  *Відступ праворуч* **3 см** — смуга закінчується перед «Білетом».
- Enter → `Білет № 14` — Arial **14, жирний**, **по правому краю**, *після* **4 пт**.

### 1.3 Назва білета
`Системи опрацювання текстів. Призначення, основні функції текстових редакторів. Система команд.`
(звичайними літерами) → Arial **13, жирний** → **Ctrl+D → Малі прописні** → по центру,
*відступи ліворуч/праворуч* **1 см**, *після* **6 пт**.

### 1.4 «Текстові редактори…»
Times 13, по ширині (Ctrl+J).
- `Текстові редактори` — **Bookman Old Style**, колір шрифту **білий**, прийом **Д**: *Заливка* **фіолетовий**, до **тексту**.
- `Текстові процесори` — те саме, заливка **темно-зелений**.
- `текстових` — курсив; `розширені` — курсив + підкреслення.

### 1.5 Заголовок «Основні функції текстових процесорів»
Courier New **12, жирний**, розріджений **3 пт**, по лівому краю, *перед* **8**, *після* **6 пт**.
Прийом **А**: *Тінь* **1½ пт темно-помаранчевий**, *Заливка* **світло-жовтий**.

### 1.6 Список з товстою лінією зліва
6 абзаців, Times 13, по ширині. Виділити всі → *Відступ ліворуч* **5 см**, *Перший рядок: Виступ* **2 см**.
Прийом **Б**: суцільна **4½ пт фіолетова**, тільки **ліва** сторона, *Параметри → ліворуч* **12 пт**.
Після списку — порожній абзац, *міжрядковий* **Точно 6 пт**.

### 1.7 Буквиця «О» і абзац Arial
1. Абзац `Одією з найпоширеніших … параметрів шрифту, абзацу, сторінки` — Arial **13**, по ширині.
2. *Вставлення → Буквиця → Параметри буквиці* → **У тексті**, шрифт **Arial**, **3 рядки**, *відстань* **0,2 см**.
3. `форматування` — жирний + курсив + підкреслення **крапками** (Ctrl+D → *Підкреслення* → точкова лінія).
4. `шрифту, абзацу, сторінки` — **курсив**, прийом **В**: *Розріджений на* **5 пт**.

### 1.8 «Процедура форматування символів…» з пунктиром знизу
Times 13, по ширині, *перед* **6 пт**.
- `Процедура форматування символів` — **жирний курсив, без підкреслення**;
- `ТИПУ` — **Arial Black 12**;
- `накреслення` — курсив;
- `інтервалів` — **Bookman Old Style, жирний**, прийом **В**: **Масштаб 150 %** і *Розріджений на* **1 пт**;
- `засобу` — прийом **Д**: *Рамка*, суцільна **¾ пт**, чорна, до **тексту**;
- `анімації` — прийом **Д**: *Рамка*, **точкова** лінія **1 пт**, чорна, до **тексту**;
- ☺ — прийом **Г**: *Wingdings*, **код 74**;
- пунктир під абзацом — прийом **Б**: штрихова лінія **1 пт фіолетова**, тільки **нижня** сторона.

### 1.9 «Форматування абзаців…»
Times 13, по ширині, *Перший рядок: Відступ* **2,5 см**, *перед* **6 пт**.

### 1.10 Заголовок «Пересування курсору по документу за допомогою:»
Courier New **12, жирний**, розріджений **2 пт**. Прийом **А**: *Тінь* **1½ пт темно-зелений**, *Заливка* **світло-зелений**.

### 1.11 «Спосіб 1 / 2 / 3» сходинкою

2-й **по центру** + *Wingdings* **код 73** (долоня);
3-й **по правому краю** + *Wingdings* **код 55** (клавіатура).

### 1.12 Заголовок «Робота з файлами»

## ВАРІАНТ 2

### 2.3 Заголовки з точковою рамкою і товстою тінню
Так зроблено **«♣ Основні теги мови HTML…»**, **«♥ Структура простого HTML-документа ♥»**,
**«♦ Теги стилістичного виділення тексту ♦»**.
1. *Вставлення → Таблиця* **1×1** на всю ширину (**16,5 см**).
2. *Властивості таблиці → Параметри*: поля клітинки ліве **0,07**, праве **0,1**, верхнє **0,07**, нижнє **0,1 см**.
3. *Конструктор таблиць → Межі → Без меж*, потім лінія **суцільна 3 пт чорна** → **Права межа** і **Нижня межа** (це тінь).
4. Курсор у клітинку → *Межі та заливка* (до **абзацу**): *Тип* **Рамка**, **точкова** лінія **1½ пт**, колір із таблиці нижче;
   *Параметри* → **2 пт**; *Заливка* — колір із таблиці. Текст по центру.
5. Над і під таблицею — порожній абзац *Точно 4–5 пт*.

| Теги стилістичного… | Times 13 жирний курсив, розріджений 3 пт | темно-червоний | світло-персиковий |
