# Інструкція для Word 2010 (російський інтерфейс)

Назви кнопок і вкладок нижче написані **точно так, як вони підписані у вашому Word**
(«Главная», «Вставка», «Разметка страницы»…). Усе робиться тільки засобами Word.

Файли: `Variant_1.docx`, `Variant_2.docx` і допоміжний `Ramky_vybir.docx` (каталог рамок, див. 2.1).

Шрифти — з аркуша та з позначок на полях: **Ar** = Arial, **Times** = Times New Roman, **CN** = Courier New,
**Bookman Old Style**, **Monotype Corsiva**. Текст скрізь чорний, як на аркуші. Кольорові тільки заливки,
рамки та лінії.

## 0. Де що знаходиться у Word 2010

| Що потрібно | Куди натискати |
|---|---|
| **Вікно «Шрифт»** | вкладка **«Главная»** → у групі **«Шрифт»** маленька стрілочка в правому нижньому куті ↘ (або **Ctrl+D**) |
| **Вікно «Абзац»** | **«Главная»** → у групі **«Абзац»** стрілочка ↘ у правому нижньому куті |
| **Вікно «Границы и заливка»** | **«Главная»** → група **«Абзац»** → кнопка **«Граница»** (квадратик з лініями, другий справа в нижньому ряду) → маленька стрілка біля неї → в самому низу списку **«Границы и заливка…»** |
| **Рамка сторінки** | вкладка **«Разметка страницы»** → кнопка **«Границы страниц»** (праворуч, група «Фон страницы») |
| **Поля, розмір паперу** | **«Разметка страницы»** → **«Поля»** → **«Настраиваемые поля…»** |
| **Символ (значок)** | вкладка **«Вставка»** → праворуч **«Символ»** → **«Другие символы…»** |
| **Буквиця** | **«Вставка»** → група «Текст» → **«Буквица»** → **«Параметры буквицы…»** |
| **Таблиця** | **«Вставка»** → **«Таблица»** → провести мишкою по клітинках |
| **Межі та заливка таблиці** | клацнути в таблицю → зверху з'являться **«Работа с таблицами»** → вкладка **«Конструктор»** (кнопки **«Заливка»**, **«Границы»**, а також «Стиль пера», «Толщина пера», «Цвет пера») і вкладка **«Макет»** (кнопка **«Свойства»**) |

### Прийоми, які повторюються

**А. Рамка з тінню + заливка абзацу.** Курсор в абзац → **«Границы и заливка…»** → вкладка **«Граница»**:
ліворуч *Тип:* **«тень»** → посередині *Тип:* суцільна лінія, **«Цвет:»**, **«Ширина:»** →
праворуч внизу **«Применить к:» абзацу** → вкладка **«Заливка»** → **«Заливка:»** колір →
**«Применить к:» абзацу** → **OK**.

**Б. Лінія тільки з одного боку.** **«Границы и заливка…»** → **«Граница»** → ліворуч *Тип:* **«другая»** →
обрати лінію, **«Цвет:»**, **«Ширина:»** → у полі **«Образец»** праворуч **клацнути по потрібній стороні**
(або натиснути кнопочки біля зразка) → **«Применить к:» абзацу**. Відступ лінії від тексту — кнопка
**«Параметры…»** → поля **«верхнее / нижнее / левое / правое»** (у пунктах).

**В. Вікно «Шрифт» (Ctrl+D):**
- вкладка **«Шрифт»**: **«Начертание»** (полужирный / курсив), **«Подчеркивание:»**,
  галочки **«зачеркнутый»**, **«малые прописные»**;
- вкладка **«Дополнительно»**: **«Масштаб:»** (розтягнути літери), **«Интервал:» Разреженный / Уплотненный**
  **«на:»** N пт, **«Смещение:» Вниз «на:»** N пт.

**Г. Значок.** **«Вставка» → «Символ» → «Другие символы…»** → **«Шрифт:»** Wingdings або Symbol →
внизу праворуч **«из:» символ (дес.)** → у поле **«Код знака:»** ввести число → **«Вставить»**.

**Д. Рамка або фон навколо одного слова.** Виділити слово → **«Границы и заливка…»** → внизу
**«Применить к:» тексту** (не абзацу!).

**Е. Вікно «Абзац»:** **«Выравнивание:»**; **«Отступ» слева / справа**; **«первая строка:» Отступ / Выступ
«на:»**; **«Интервал» перед / после**; **«междустрочный:»** Одинарный / Точно / Множитель, **«значение:»**.

### Спочатку (для обох файлів)
1. **«Разметка страницы» → «Поля» → «Настраиваемые поля…»**: верхнее **1,5**, нижнее **1,5**, левое **2,5**,
   правое **2 см**; вкладка **«Размер бумаги»** → **A4**.
2. **Ctrl+D** → **Times New Roman**, **13** → кнопка **«По умолчанию…»** → *всех документов* → OK.
3. Вікно **«Абзац»**: перед **0**, после **0**, междустрочный **Одинарный** → **«По умолчанию…»**.

  **«Цвет пера»** фіолетовий → **«Границы» → «Внутренняя вертикальная граница»**.
- 3-тя клітинка → **«Конструктор» → «Заливка»** жовта.
- `START - встановлює число, яким буде починатися список.` — як TYPE.

### 2.14 Нижня смуга
**Monotype Corsiva 14**, **Ж**, по центру, *перед* **6 пт**; **«Заливка»** світло-зелена, без рамки.
