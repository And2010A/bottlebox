# osu! bot by Claude

Окрема програма-симулятор: ти вибираєш **будь-яку карту osu!** (`.osu` або `.osz`),
а бот сам її проходить. Підтримуються режими **osu!** (кола, слайдери, спінери) та
**osu!catch** (фрукти). На екрані видно фон карти, як рухається курсор або кетчер, які
клавіші натискаються, точність і комбо, а в кінці є екран результатів із рангом.

> Програма **не підключається** до клієнта osu! і серверів. Карта лише читається з файлу,
> гра малюється у власному вікні. Нічого не відправляється на рейтинги.
> Проєкт фанатський і не пов'язаний з osu!/ppy.

## Як запустити

1. Завантаж `OsuBotClaude.exe` з релізу **osu-bot-latest** (вкладка *Releases* репозиторію)
   або з артефакту останнього запуску в *Actions → Build osu! bot (.exe)*.
2. Запусти exe. Windows SmartScreen може попередити про «невідомого видавця»:
   *Докладніше → Виконати в будь-якому разі*.
3. Натисни **«Вибрати карту»** (вікно одразу відкриває папку `osu!/Songs`, якщо вона є)
   або просто перетягни файл `.osu` / `.osz` у вікно. Є також вбудована **демо-карта**.
4. Обери режим бота, моди й натисни **ГРАТИ** (Enter).

## osu! та osu!catch

* Карти osu! можна грати в обох режимах: osu!catch уміє перетворювати звичайні карти, як і сама гра.
* Карти osu!catch (складності на кшталт *Cup / Salad / Platter / Rain / Overdose*) грають тільки в osu!catch.
* Карти osu!taiko та osu!mania не підтримуються: у списку складностей вони позначені й вимкнені.

У osu!catch бот рухає кетчер і робить даш та гіпердаш (червоні фрукти), як справжній гравець.
Фрукти, краплі, дрібні краплі й банани генеруються за правилами гри.

## Фон карти

Фон береться з самої карти: розмитий у меню, на весь екран під час гри та на екрані результатів.
Під час вступу й перерв фон світлішає, як в osu!. Кнопка «Затемнення» змінює затемнення
(35 / 55 / 70 / 85%).

## Відео-фон

Якщо в карті є відео (рядок `Video,...` у `[Events]`, файли .mp4 / .avi / .flv тощо),
воно грає замість картинки синхронно з музикою, з DT/HT так само прискорюється
чи сповільнюється. Вимкнути можна кнопкою «Відео» в меню. Відео декодує окремий
процес ffmpeg, який входить в exe, тому гра не гальмує.

## Плавність

* Тіла слайдерів малюються заздалегідь, по кілька штук за кадр, а не в момент появи.
* Під час гри вимикається збирач сміття Python, щоб не було мікрофризів.
* Кола наближення малюються напряму, без масштабування картинок.

## Режими бота

**Ціль: ранг.** Обираєш, який ранг має вийти: `SS S A B C D F`.
Бот навмисно влучає в потрібні вікна таймінгу (300/100/50) або промахується,
щоб результат відповідав правилам рангів osu!:

| Ранг | Умова (як у osu!) |
|---|---|
| SS | 100% точність |
| S | понад 90% «300», ≤1% «50», жодного промаху |
| A | понад 80% «300» без промахів (або понад 90% із промахами) |
| B | понад 70% «300» без промахів (або понад 80%) |
| C | понад 60% «300» |
| D | усе інше |
| F | провал: HP впало до нуля |

Рангу «E» в osu! немає, тому його немає й тут. В osu!catch ранги рахуються за відсотком спійманого:
SS = 100%, S > 98%, A > 94%, B > 90%, C > 85%, D — менше.

**Скіл гравця (1–10).** Чесний режим: бот поводиться як людина з обмеженнями:
розкид таймінгу, максимальна швидкість руки, точність прицілювання, швидкість спіну,
іноді випускає слайдер. Ранг тут ніхто не задає, він залежить від складності карти.
Якщо хочеш перевірити, «наскільки добре бот пройде складні карти», тобі сюди:
на швидких джампах (високий BPM, DT) бот почне запізнюватися і промахуватися.

## Моди

`EZ` (легше), `HT` (повільніше), `HR` (важче, карта перевертається), `DT` (у 1.5 раза швидше),
`NF` (без провалу). З DT/HT музика прискорюється чи сповільнюється разом із картою.

## Керування

| Клавіша | Дія |
|---|---|
| Enter | грати |
| Esc | у меню / вихід |
| R | перезапустити (новий випадковий прохід) |
| P | пауза |
| Space | пропустити вступ (бот і сам натисне «skip» через 3 с) |
| F11 | повний екран (вікно також можна розтягувати, текст лишається чітким) |

## Як це працює

* `osubot/beatmap.py` читає формат `.osu`: таймінги, слайдери (bezier, perfect circle,
  linear, catmull), тіки й повтори, стеки, кольори комбо, моди EZ/HR/DT/HT.
* `osubot/sim.py` — сам бот: заздалегідь планує рух курсора й натискання клавіш, а потім
  оцінює їх за правилами osu! (вікна таймінгу з OD, радіус кола з CS, follow-circle слайдера,
  оберти спінера). Звідси точність, комбо, очки, HP та ранг.
* `osubot/catch.py` — osu!catch: перетворення карти на фрукти, гіпердеші, бот-кетчер.
* `osubot/menu.py`, `play.py`, `play_catch.py`, `results.py`, `game.py` — вікно на pygame.
* Шрифт — [Nunito](https://github.com/googlefonts/nunito) (SIL Open Font License, див. `osubot/fonts/OFL.txt`).

## Збірка самостійно (Windows)

```bat
cd osu-bot
pip install -r requirements.txt pyinstaller pillow
python tools/make_icon.py icon.png
pyinstaller --onefile --windowed --name OsuBotClaude --icon icon.png --add-data "osubot/fonts;osubot/fonts" --collect-all imageio_ffmpeg main.py
```

Готовий файл з'явиться в `dist\OsuBotClaude.exe`. Без збірки можна запустити так: `python main.py`.
Тести: `python -m pytest tests`.
