# Chess Assistant (Stockfish)

Програма для Windows: бачить шахову дошку на екрані (lichess, chess.com або будь-яка
інша програма), за одним натисканням клавіші рахує найкращий хід через Stockfish,
називає його вголос і сама робить хід мишкою.

## Як отримати .exe

**Готова збірка.** Кожен push у цю папку збирає програму на GitHub Actions
(workflow «Build ChessAssistant.exe»). Відкрийте вкладку **Actions** → останній
успішний запуск → внизу артефакт **ChessAssistant-windows** (zip). У ньому:

- `ChessAssistant.exe` — програма;
- `stockfish.exe` — рушій (GPLv3, ліцензія в `Stockfish-LICENSE.txt`);
- `README.md` — ця інструкція.

Розпакуйте все в одну папку.

**Зібрати самому.** Встановіть Python 3.10+ з python.org (галочка *Add to PATH*),
запустіть `build.bat`. Готовий файл — `dist\ChessAssistant.exe`. Поруч покладіть
`stockfish.exe` з https://stockfishchess.org/download/ (або вкажіть шлях у `config.json`).

## Як користуватись

1. Запустіть `ChessAssistant.exe` (відкриється чорне вікно з підказками — не закривайте його).
2. Відкрийте партію так, щоб на дошці стояла **початкова позиція** і дошку було видно повністю.
3. **Калібрування (один раз):** наведіть курсор на **лівий верхній кут** дошки — `F8`,
   потім на **правий нижній кут** — `F8`. Точність до пікселя не потрібна: межі
   дошки уточнюються автоматично. Програма запам'ятає вигляд фігур і визначить,
   за кого ви граєте.
4. Коли ваш хід — натисніть **`F9`**: програма розпізнає позицію, Stockfish знайде хід,
   програма скаже його вголос і зробить мишкою. Повторюйте `F9` на кожному ході.

| Клавіша | Дія |
|---|---|
| `F8` | калібрування (двічі: лівий верхній кут, правий нижній кут) |
| `F9` | знайти хід і зробити його мишкою |
| `F10` | лише підказати хід (сказати і написати, мишку не чіпати) |
| `F7` | перевернути дошку, якщо програма сплутала білі/чорні |
| `F12` | вихід |

Калібрування зберігається у `calibration.npz`. Робити його заново треба, якщо ви
перемістили/змінили розмір вікна браузера, змінили масштаб сторінки або тему фігур/дошки.

## Налаштування (`config.json`, створюється при першому запуску)

| Параметр | За замовчуванням | Що означає |
|---|---|---|
| `think_time_sec` | `1.0` | скільки секунд думає Stockfish |
| `skill_level` | `20` | сила гри Stockfish, 0–20 |
| `threads`, `hash_mb` | `2`, `128` | ресурси для рушія |
| `speak` | `true` | озвучувати хід голосом Windows |
| `return_mouse` | `true` | повертати курсор на місце після ходу |
| `click_delay_sec` | `0.08` | пауза між рухами мишки |
| `stockfish_path` | `""` | шлях до рушія, якщо він не поруч з exe |
| `hotkey_*` | `f7`…`f12` | клавіші |

## Якщо щось не так

- **«Не вдалося розпізнати дошку»** — дошку закрило інше вікно, її зсунули або змінили
  масштаб. Зробіть калібрування заново. Програма зберігає `debug_board.png` — там видно,
  що вона «бачить».
- **Мишка клацає не туди** — у Windows масштаб екрана не 100% і вікно на іншому моніторі;
  переконайтесь, що калібрування робили на тому самому моніторі, де дошка.
- **Перетворення пішака** — обирається ферзь (або фігура, яку вибрав Stockfish) у
  стандартному меню lichess / chess.com.
- **Шахи Фішера (960)** не підтримуються.

## Чесна гра

Використовуйте програму для аналізу, тренування та ігор проти комп'ютера.
У рейтингових партіях проти людей на lichess / chess.com допомога рушія заборонена
правилами сайтів — акаунт буде заблоковано.
