# Glock 19 — Fabric mod for Minecraft 1.21.11

Adds a Glock 19 pistol with a 3D held model, custom sounds, a 15-round magazine and an ammo HUD.

| | |
|---|---|
| **Fire** | Right-click (semi-auto; holding fires about 5 rounds/s) |
| **Reload** | `R` (rebindable under Options → Controls → Glock 19) |
| **Damage** | 6 (3 hearts), hitscan, 64-block range |
| **Ammo** | `9mm Round` items in your inventory; creative mode reloads for free |

## Items and recipes

- **Glock 19**: `III` / ` RT` / ` B ` with I = iron ingot, R = redstone, T = tripwire hook, B = black dye.
  It comes with a full magazine.
- **9mm Round ×16**: shapeless, copper ingot + gunpowder + iron nugget.

Both items also appear in the Combat creative tab.

## What's included

- `assets/glock19/models/item/glock_19.json`: 3D model shown in first and third person (opens in Blockbench).
  The inventory and dropped-item views use the pixel-art icon `glock_19_icon.png`.
- `assets/glock19/sounds/`: three gunshot variants, an empty-magazine click and a reload sequence.
- HUD (bottom left while holding the gun): magazine count, reserve rounds, one pip per round, and a reload bar.

## Building

Needs JDK 21+ (CI uses 25):

```
./gradlew build
```

The jar lands in `build/libs/`. Put it in your `mods/` folder together with Fabric API for 1.21.11.
GitHub Actions (`.github/workflows/glock19-build.yml`) builds every push to `glock19-mod/` and attaches the jar to the run.

## Changing the art or sounds

Textures, models and sounds are generated by `tools/generate_assets.py` (needs numpy, Pillow and ffmpeg):

```
python3 tools/generate_assets.py
```

To use your own recordings instead, replace the `.ogg` files in `src/main/resources/assets/glock19/sounds/`.
They must be **mono** Ogg Vorbis, or Minecraft won't play them positionally.
If you tweak the held position in Blockbench, stop re-running the script, or it will overwrite your edits.
